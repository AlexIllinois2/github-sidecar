安装方法

  1. Linux (Fedora/RHEL)： sudo cp ca.crt /etc/pki/ca-trust/source/anchors/dev-sidecar-rs-ca.crt && sudo update-ca-trust
  2. Linux (Debian/Ubuntu)： sudo cp ca.crt /usr/local/share/ca-certificates/dev-sidecar-rs-ca.crt && sudo update-ca-certificates
  3. Windows：双击 ca.crt → 安装证书 → 本地计算机 → “将所有的证书都放入下列存储” → 受信任的根证书颁发机构。
  4. macOS：双击 ca.crt 导入“系统”钥匙串，然后设置为“始终信任”。
  5. Firefox：设置 → 隐私与安全 → 证书 → 查看证书 → 导入 ca.crt（Firefox 用自己的证书库）。
  6. Node.js：export NODE_EXTRA_CA_CERTS=/path/to/ca.crt

基本设置

启动后自动打开管理页面 启动时自动设置系统代理，退出时恢复 对所有 HTTPS 做 MITM（默认只对勾选 MITM 的规则解密；需要 CA） 忽略上游 TLS 证书校验（仅调试用）
